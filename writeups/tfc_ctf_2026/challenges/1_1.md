# 1+1

`1+1` is a crypto challenge that hands out ten ~512-bit integers `x_i = p*q_i + r_i`; the flag is hidden as the common approximate divisor `p`. Key idea: an SDA/AGCD lattice reduction (LLL) recovers `p` even though every sample has a different random prime multiplier and a 444-bit noise term.

## Recon

`challenge.zip` contains the generator and its output.

```
$ unzip -l challenge.zip
  chall.sage    261
  output.py    3085
```

`chall.sage`:

```python
from Crypto.Util.number import getPrime, bytes_to_long
import random

rbit = 444
pbit = 512

p = bytes_to_long(open('flag','rb').read())

xs = [p * getPrime(pbit) + random.randint(1,2**rbit) for _ in range(10)]

open('output.py','w').write(f'xs = {str(xs)}')
```

Observation: each `x_i = p * q_i + r_i` with a shared hidden `p`, a fresh random 512-bit prime `q_i`, and noise `r_i in [1, 2^444]`. `p` itself is the flag interpreted big-endian (`bytes_to_long`).

## Analysis

Observation -> hypothesis: all ten values share a hidden factor `p` up to a small additive error, so a plain `gcd` fails because of the noise. This is the Approximate Common Divisor (AGCD) problem.

Technique (named in the crypto knowledge base): the Simultaneous Diophantine Approximation (SDA) lattice. Build a lattice whose short vectors encode the ratios `q_i/q_1`; then read `q_1` from the first coordinate and recover `p = (x_1 - r_1)/q_1`.

Confirmation: with `t = 10`, `rho = 444`, and the basis

```
M[0,0] = 2**(rho+1)
M[0,i+1] = xs[i+1]      (i = 0..t-2)
M[i+1,i+1] = -xs[0]
```

an LLL reduction returns a short first row whose first entry is `q_1 * 2**(rho+1)`. Dividing recovers `q_1`, then `r_1 = x_1 mod q_1` and `p = (x_1 - r_1)//q_1`. The recovered `p` decodes to ASCII starting with `TFCCTF{`, confirming the AGCD hypothesis.

## Exploit

1. Build the SDA lattice, LLL it, extract `p`, and decode it as bytes (`solve.sage`):

```sage
xs = [ ... ]  # the ten values from output.py
rho = 444
t = len(xs)
M = Matrix(ZZ, t, t)
M[0,0] = 2**(rho+1)
for i in range(t-1):
    M[0, i+1] = xs[i+1]
    M[i+1, i+1] = -xs[0]
L = M.LLL()
q1 = L[0,0] // (2**(rho+1))
r1 = xs[0] % q1
p = abs((xs[0] - r1) // q1)
print("q1 bits:", q1.nbits())
print("p bits:", p.nbits())
import binascii
b = int(p).to_bytes((p.nbits()+7)//8, 'big')
print("bytes:", b)
print("as text:", b.decode('latin1', errors='replace'))
```

The recovered `p` decodes directly to the flag text (printed by the `as text:` line).

## Full chain

1. `unzip challenge.zip`
2. Copy the `xs` list from `output.py` into the `xs = [...]` line of the snippet above.
3. `sage solve.sage` — the `as text:` line is the flag.

## Lessons

- A list of `p*q_i + r_i` samples is the AGCD signature: the SDA lattice recovers `p` without factoring anything.
- Choose the lattice so the unknown `q_i/q_1` ratios sit in the shortest vector; `2**(rho+1)` scaling keeps `q_1` readable from coordinate 0.
- `bytes_to_long(flag)` means recovering `p` = recovering the flag; decode big-endian with `int.to_bytes`.
